# Практическая задача: CI/CD

## Цель

Настроить автоматическую сборку и публикацию статического сайта при изменении ветки `main`.

## Используемые инструменты

- Git;
- GitHub;
- GitHub Actions;
- Python 3.12;
- MkDocs 1.6.1;
- Material for MkDocs.

## Этапы pipeline

Pipeline выполняет следующие действия:

1. получает исходный код из репозитория;
2. устанавливает Python 3.12;
3. устанавливает зависимости из `requirements.txt`;
4. выполняет `mkdocs build --strict`;
5. формирует каталог `site`;
6. загружает собранный сайт как артефакт GitHub Pages;
7. публикует сайт на GitHub Pages.

## Условие запуска

Публикация выполняется при отправке изменений в ветку `main`.

Также workflow можно запустить вручную через GitHub Actions.

## Проверка результата

После изменения `docs/index.md` был выполнен `git push`.

GitHub Actions успешно выполнил workflow, после чего обновлённая версия сайта стала доступна на GitHub Pages.

## Вывод

Автоматизация позволяет исключить ручную сборку сайта: изменение исходных Markdown-файлов запускает pipeline, который проверяет проект, собирает статические файлы и публикует результат.
