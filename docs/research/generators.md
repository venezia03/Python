# Сравнение статических генераторов

## Цель

Сравнить инструменты, которые позволяют публиковать результаты экспериментов в виде статического сайта.

## Выбранные генераторы

Для сравнения рассматриваются:

1. MkDocs + Material
2. Sphinx + MyST
3. Pelican
4. Nikola

## Критерии сравнения

| Критерий | MkDocs + Material | Sphinx + MyST | Pelican | Nikola |
|---|---|---|---|---|
| Python | Да | Да | Да | Да |
| Markdown | Да | Да, через MyST | Да | Да |
| Документация проекта | Отлично | Отлично | Хорошо | Хорошо |
| Научные тексты | Хорошо | Отлично | Хорошо | Хорошо |
| Навигация | Отлично | Отлично | Хорошо | Хорошо |
| Поиск | Встроенный | Расширяется плагинами | Расширяется | Расширяется |
| Темы | Material и другие | Sphinx themes | Jinja-шаблоны | Темы и шаблоны |
| Простота настройки | Высокая | Средняя | Средняя | Средняя |
| CI/CD | Удобно | Удобно | Удобно | Удобно |

## Результат

Для данной лабораторной работы выбран **MkDocs + Material**.

Причины выбора:

- простой YAML-конфиг;
- удобная навигация;
- встроенный поиск;
- хорошая поддержка Markdown;
- удобная интеграция с GitHub Pages;
- возможность использовать один и тот же проект в локальной разработке и CI/CD.

При этом Sphinx + MyST является сильной альтернативой для больших научных проектов, особенно если требуется сложная система документации и большое количество расширений.

## Вывод

MkDocs + Material лучше всего подходит для данного учебного проекта благодаря простоте настройки, хорошему внешнему виду и удобной автоматизации сборки.
